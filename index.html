⚙️ Aufbau des fremderregten GSM

Der fremderregte GSM hat zwei getrennte Stromkreise:

🧲 Erregerkreis (Index f)

Speist die Feldspule. Erzeugt das Magnetfeld Φ.

⚡ Ankerkreis (Index A)

Führt den Ankerstrom IA. Erzeugt mit Φ das Drehmoment M.

🧮 Wichtige Formeln

Ankerspannung: UA = RA · IA + Ui
Induzierte Spannung: Ui = c · Φ · n
Drehmoment: M = c · Φ · IA
Drehzahl: n = (UA − RA · IA) / (c · Φ)
Aufnahmeleistung: Pel = UA · IA + IF · UF

📈 Verhalten bei Belastung

M ↑ → IA ↑ → Spannungsfall RA·IA ↑ → Ui ↓ → n sinkt leicht.

→ Harte Drehzahlkennlinie.

🔥 Gefahr 1: Anker ohne Erregung

ZUERST Erregung, DANN Anker!

Ohne Erregung: IA ≈ UA / RA = vielfacher Nennstrom → Wicklung brennt.

💥 Gefahr 2: Erregung im Betrieb aus

Niemals im Betrieb!

Φ → 0 → n → ∞ → Anker zerreißt → Lebensgefahr!

✅ Richtige Inbetriebnahme

  1. Schalter offen, Stellwiderstände auf Maximum
  2. Erregung EIN → If = 0,35 A
  3. Anker EIN, UA langsam von 0 auf 220 V
  4. Werte kontrollieren, Messung durchführen

Aus: UA → 0, Anker aus, dann Erregung aus.
