⚙️ Aufbau des fremderregten GSM

Der fremderregte Gleichstrommotor besitzt zwei getrennte Stromkreise, die von zwei voneinander unabhängigen Spannungsquellen gespeist werden:

🧲 Erregerkreis (Index f)

Speist die Feldspule im Ständer.
Erzeugt das konstante Magnetfeld Φ.

⚡ Ankerkreis (Index A)

Führt den Ankerstrom IA durch den Läufer.
Erzeugt zusammen mit Φ das Drehmoment M.

🧮 Die wichtigsten Formeln

Ankerspannungsgleichung: UA = RA · IA + Ui
Induzierte Spannung (2. MGl.): Ui = c · Φ · n
Drehmoment (1. MGl.): M = c · Φ · IA
Drehzahl: n = (UA − RA · IA) / (c · Φ)
Elektrische Aufnahmeleistung: Pel = UA · IA

📈 Verhalten bei Belastung

Wird das Drehmoment M erhöht, so muss der Ankerstrom IA steigen (weil M ~ IA). Durch den größeren Spannungsfall RA·IA sinkt Ui – und damit auch n leicht.

→ Der fremderregte GSM hat eine harte Drehzahlkennlinie: n nimmt mit steigender Last nur wenig ab.

🔥 Gefahr 1: Anker ohne Erregung einschalten

Lebenswichtige Regel: ZUERST Erregung, DANN Anker!

Ohne Erregung ist Φ ≈ 0 → Ui = c·Φ·n ≈ 0. Dann gilt:

IA = (UA − Ui) / RA ≈ UA / RA

Da RA sehr klein ist (oft < 1 Ω), fließt ein Vielfaches des Nennstroms → Wicklung brennt durch.

💥 Gefahr 2: Erregung im Betrieb unterbrechen

Niemals die Erregung im Betrieb abschalten – der Motor "geht durch"!

Fällt If aus → Φ → 0:

n = (UA − RA·IA) / (c · Φ) → ∞

Der Motor dreht immer schneller → die Fliehkräfte zerreißen den Anker → herumfliegende Bruchstücke = Lebensgefahr!

✅ Richtige Inbetriebnahme – Schritt für Schritt

  1. Alle Schalter öffnen, alle Stellwiderstände auf Maximum
  2. Erregerkreis einschalten → Magnetfeld aufbauen (If = IfN = 0,35 A)
  3. Ankerkreis einschalten, UA langsam von 0 auf UAN = 220 V hochfahren
  4. Motor läuft hoch, Betriebswerte kontrollieren
  5. Messung durchführen

Ausschalten in umgekehrter Reihenfolge:
UA → 0, Anker aus, dann erst Erregung aus.

Beantworte diese drei Fragen schriftlich in deinem Laborbericht. Verwende dafür deine eigenen Messwerte und Diagramme.

  2. b) Ankerstromverhalten: Beschreibe den Verlauf von IA = f(M). Welcher mathematische Zusammenhang lässt sich erkennen? Welche theoretische Formel bestätigt das?
  3. c) Leistungsverhalten: Beschreibe den Verlauf der Kennlinie Pel = f(M). Warum steigt die elektrische Aufnahmeleistung mit dem Drehmoment an?

👨‍🏫 Musterlösung Auswertefragen

a) Drehzahlverhalten: Die Drehzahl sinkt nahezu linear und nur gering ab.
Δn = n0 − nN = 2500 − 2300 = 200 1/min → Δn / n0 ≈ 8 %
→ hartes (Nebenschluss-)Verhalten.

b) Ankerstromverhalten: IA steigt direkt proportional / linear mit M.
Aus der 1. Maschinengleichung: M = c · Φ · IA → bei Φ = const. gilt IA ~ M.
Der Offset im Leerlauf (IA0 ≈ 0,15 A) deckt Reibungs- und Eisenverluste ab.

c) Leistungsverhalten: Pel wächst linear mit M, weil Pel = UA · IA bei konstantem UA und IA ~ M. Im Leerlauf werden ≈ 33 W aufgenommen, um die mechanische Leistung Pmech = 2π·n·M plus Verluste zu liefern.
